# Security policy

Please **don't open a public issue** for security problems.

Report vulnerabilities privately through GitHub: open the affected repository's **Security** tab and choose
**Report a vulnerability**. We'll acknowledge your report as quickly as we can and keep you updated while we work on a
fix.

This policy applies to every repository in the [Mothfire Labs](https://github.com/mothfire-labs) organization unless a
repository provides its own.
